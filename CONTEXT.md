# Glossary

- Anime: A title-level record identified by a name and its release start year.
- Ongoing Anime: An Anime where yearTo is unknown (null).
- API Key: A client credential used to authenticate access to protected API endpoints.
- Revoked API Key: An API Key that must no longer grant access.
- Client: A caller (service, script, or user-owned app) that invokes the API using an API Key.
